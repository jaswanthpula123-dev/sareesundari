# 👑 Saree Sundarii – Royal Indian Handloom Silk Sarees & Bridal Heirlooms

**Saree Sundarii** is a luxury, responsive full-stack Indian handloom saree e-commerce web platform. It pairs the timeless grandeur of Indian handloom weaves (Kanjivaram, Banarasi, Paithani, Mysore Silk, Kota Doria, and Jamdani) with a modern, high-performance MERN architecture, rich interactive category navigations, weight/blouse selection, and a comprehensive administration suite.

---

## 🎨 Design Theme & Royal Aesthetics
- **Deep Maroon (`#5B0E2D` / `#38050c` / `#24030F`)**: Symbolizes sacred kumkum, bridal muhurthams, and royal Indian heritage.
- **Antique Gold (`#D4AF37` / `#B8861D` / `#E5A93C`)**: Reflects authentic 24K gold dipped silver zari brocades.
- **Cream White (`#FDFBF7` / `#FFFAF3`)**: Clean, elegant silk canvas ensuring optimal contrast and readability.
- **Typography**: Playfair Display for regal serif headlines, Cinzel Decorative accents, and Plus Jakarta Sans for crisp readability.

---

## 🛠️ Technology Stack

### Frontend
- **React.js 19** with **Vite**
- **Tailwind CSS v4** with luxury handloom utility classes and continuous infinite marquee
- **React Router DOM v7**
- **Axios** with JWT request & response interceptors
- **Lucide React** luxury iconography

### Backend
- **Node.js** & **Express.js**
- **RESTful API** architecture
- **JWT (JSON Web Token)** authentication & role-based access control
- **bcryptjs** password hashing
- **Dual-mode Data Store**: MongoDB with automatic in-memory fallback pre-seeded with 34 authentic handloom sarees across 8 royal categories

- **Top Announcement Ribbon**: Continuous smooth marquee featuring festive promo `SUNDARI20`, WhatsApp concierge hotline, and Silk Mark guarantee.
- **Brand Identity**: Royal gold crown insignia with Saree Sundarii typography.

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/jaswanthpula123-dev/sareesundari.git
cd sareesundari
```

### 2. Install Dependencies
```bash
# Backend dependencies
cd backend
npm install

# Frontend dependencies
cd ../frontend
npm install
```

### 3. Run the Development Environment
```bash
# Terminal 1: Backend Server (Port 5000)
cd backend
npm run dev

# Terminal 2: Frontend Client (Port 5173)
cd frontend
npm run dev
```
